# ProgramerAI — Лендинг Тарасова Ильи

Динамичная лендинг-страница для разработчика в стиле "Vibe Coding". Современный дизайн, анимации, адаптивная верстка.

## Стек

- **HTML5** — семантическая разметка
- **CSS3** — адаптивный mobile-first дизайн, CSS Grid, Flexbox, кастомные свойства
- **JavaScript (ES6+)** — интерактивность, анимации, обработка форм

## Как запустить на локальной машине (VS Code)

### 1. Клонировать репозиторий
bash
git clone https://github.com/ваш-username/ProgramerAI.git
cd ProgramerAI


### 2. Установить расширение Live Server
- Откройте VS Code
- Перейдите в раздел расширений (Ctrl+Shift+X)
- Найдите "Live Server" (автор: Ritwick Dey)
- Нажмите "Установить"

### 3. Запустить проект
- Откройте папку с проектом в VS Code
- Нажмите правой кнопкой мыши на файл `index.html`
- Выберите "Open with Live Server"
- Или нажмите кнопку "Go Live" в правом нижнем углу VS Code

### 4. Открыть в браузере
- Проект автоматически откроется в браузере по адресу `http://127.0.0.1:5500`
- Для остановки сервера нажмите кнопку "Port: 5500" в правом нижнем углу VS Code
